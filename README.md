Calculator Web Application 🧮
A simple and responsive calculator web app built using HTML, CSS, and JavaScript.
It performs basic arithmetic operations with a clean and user-friendly interface.

✨ Features
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🔢 Decimal number support
🧹 Clear (C) button
📱 Responsive layout
🎨 Modern calculator UI
🛠️ Technologies Used
HTML5 – Structure of the calculator
CSS3 – Styling and layout (Grid system)
JavaScript – Calculation logic and user interaction
